# 한화솔루션 DCF 가치평가 & 몬테카를로 시뮬레이터

**배포 링크:** (Streamlit Cloud 배포 후 여기에 주소 입력)

큐셀(신재생에너지) 부문을 중심으로 한 한화솔루션(009830)의 기업가치를 DCF(현금흐름할인법)로 평가하고, 핵심 가정의 불확실성을 몬테카를로 시뮬레이션으로 분석하는 웹 애플리케이션입니다.

## 만든 이유

엑셀 DCF 모델은 가정 하나를 바꿀 때마다 민감도 표와 시나리오를 다시 돌려야 하고, "주당가치 = 얼마"라는 하나의 숫자만 남기 쉽습니다. 가정을 바꾸는 즉시 결과·민감도·확률분포가 함께 갱신되는 도구를 만들어, 가치평가 결과를 하나의 숫자가 아니라 범위와 확률로 볼 수 있게 하는 것이 목표였습니다.

## 주요 기능

- **DCF 계산:** 매출 성장률, 영업이익률, CAPEX 등 가정 → 연도별 FCF → 기업가치 → 주당가치
- **계산 과정 표:** 모든 중간값을 표로 공개해 엑셀로 교차검증 가능
- **민감도 분석:** WACC × 영구성장률 5×5 표
- **몬테카를로 시뮬레이션:** WACC, 영구성장률, 영업이익률, 성장률을 확률분포로 두고 최대 5만 회 반복 (NumPy 벡터 연산)
- **역DCF:** 현재 주가를 정당화하는 데 필요한 영업이익률을 이분법으로 역산

## 기본 가정과 출처

| 항목 | 기본값 | 근거 |
|---|---|---|
| 기준연도 매출 | 13.35조원 | 2025년 연결 실적 (회사 발표, 2026.2) |
| 2026년 성장률 | 20% | 증권사 2026년 매출 전망(약 16.7조원)을 다소 보수적으로 반영 |
| 영업이익률 | 1% → 10% | 2025년 영업적자, 2026년 흑자전환 전망을 반영한 가정 |
| 순차입금 | 11.55조원 | 2026년 상반기 말 12.72조원에서 유상증자 조달액 1.17조원 차감 (추정) |
| 발행주식수 | 225.9백만주 | 유상증자 후 시가총액 ÷ 주가로 역산 |
| WACC / 영구성장률 | 8.5% / 1.5% | 사용자 가정 |

모든 값은 앱에서 수정할 수 있으며, 정확한 분석을 위해서는 DART 최신 공시로 업데이트가 필요합니다.

## 분석에서 발견한 점

기본 가정에서 주당가치는 약 7,500원으로 현재 주가(약 3.3만원)를 크게 밑돕니다. 역DCF로 계산하면 시장은 5년 뒤 영업이익률 약 13.5%를 기대하는 셈입니다. 또한 순차입금이 기업가치의 대부분을 차지하기 때문에 WACC가 1%p만 변해도 주당가치가 크게 흔들리는데, 이는 차입금이 많은 기업의 주식이 가정 변화에 민감하다는 점(재무 레버리지 효과)을 보여줍니다.

## 한계

- 부문별(신재생·케미칼·첨단소재) 분리 없이 연결 기준으로 추정 → 향후 SOTP(부문별 합산) 방식으로 확장 가능
- 미국 첨단제조 세액공제(AMPC) 등 정책 변수, 비지배지분, 지분법 투자자산을 별도로 반영하지 않음
- 몬테카를로의 변수 간 상관관계를 고려하지 않음(독립 정규분포 가정)

## AI 도구 활용과 검증

Claude를 활용해 코드를 작성했으며, 다음 방법으로 결과를 검증했습니다.

1. **자동 테스트 (`test_dcf.py`):** 손으로 계산 가능한 단순 케이스(영구연금 FCF 15, WACC 10% → 기업가치 150)로 계산 로직 검증
2. **엑셀 교차검증:** (직접 수행 후 작성) 기본 가정으로 엑셀 DCF를 만들어 앱 결과와 비교
